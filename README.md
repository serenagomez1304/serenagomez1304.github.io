# serenagomez1304.github.io

Personal site of Serena Gomez, AI/ML + AI security engineer.

Live at **https://serenagomez1304.github.io**

- Plain HTML, CSS and JavaScript. No build step, no frameworks.
- The painting comes alive with a hand-written WebGL shader (rain on the glass, candle light, lamp, depth parallax).
- Rain and candle sounds are synthesized live with the Web Audio API.
- Press <kbd>`</kbd> on the site (or click the laptop in the painting) to open the terminal.

To update: edit `index.html` (or replace images in `assets/`) and push to `main`. GitHub Pages redeploys automatically.
