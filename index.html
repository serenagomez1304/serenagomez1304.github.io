FedZTA: securing multi-agent AI systems

When AI agents work together, they call tools over MCP and message each other over A2A. Any one of them can be tricked, impersonated or go off-script, and the others will happily follow.

FedZTA is a zero-trust security layer I co-developed that never trusts an agent by default. It keeps verifying who each agent is and whether what it’s doing makes sense, on every exchange.

AGAI Research Group, CMU · submitted to NeurIPS 2026 · selected for CMU’s Scholar-to-Scholar poster showcase
